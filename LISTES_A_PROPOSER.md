# Faire connaître Radar Bourse gratuitement (sous pseudo)

Les liens venant d'autres sites sont ce qui fait le plus monter un site dans Google. Voici où proposer le projet, avec les textes prêts à copier.
Une seule proposition par endroit, jamais de spam : un refus n'est pas grave.

## 1. Ton dépôt GitHub (2 minutes, le plus simple)

Sur la page du dépôt, clique sur la roue dentée à côté de **About** (à droite) :

- **Description** : `Prévisions bourse et crypto par IA, gratuites et vérifiées publiquement (agitation, chances à un mois, ratés compris).`
- **Website** : l'adresse de ton site.
- **Topics** : `stock-market`, `stock-prediction`, `machine-learning`, `finance`, `cryptocurrency`, `python`, `github-pages`, `french`.

Les « topics » font apparaître le dépôt dans les recherches de GitHub et sur des sites qui listent les projets par sujet (LibHunt, par exemple).

## 2. La liste « awesome-quant »

C'est une liste très connue de projets libres sur la finance quantitative (dépôt `wilsonfreitas/awesome-quant` sur GitHub).
On y propose un projet par une « pull request » qui ajoute une ligne. Texte proposé (en anglais, comme la liste) :

```
- [Radar Bourse](https://github.com/<ton-pseudo>/radar-bourse) - Free, open-source stock & crypto forecasts (1-month volatility and direction) with public walk-forward validation, published as a static site.
```

Mets la ligne dans la section Python la plus proche (prévision ou outils de trading), en respectant l'ordre de la liste.

## 3. AlternativeTo

Sur alternativeto.net, crée une fiche (compte gratuit, pseudo) :

- **Nom** : Radar Bourse
- **Alternative à** : Danelfin, Zonebourse, TradingView
- **Description** : `Prévisions gratuites par IA pour plus de 200 actions et cryptos : agitation prévue, chances à un mois, comparaisons, classements. Chaque prévision est vérifiée publiquement, ratés compris. Sans inscription ni publicité.`
- **Mots-clés** : stock market, stock prediction, crypto, free, open source

## 4. Product Hunt (une seule fois)

Présentation gratuite d'un nouveau projet, sous pseudo. Texte court :

`Radar Bourse — Free AI stock & crypto forecasts that publish their own track record (misses included).`

## Ce qu'on ne fait pas

- Pas de faux avis, pas de messages automatiques, pas d'achat de liens : Google pénalise, et c'est contraire à l'esprit du site.
- Jamais ton vrai nom : le pseudo GitHub suffit partout.
